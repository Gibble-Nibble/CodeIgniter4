## Deployment

The live archive is hosted on an **Oracle Cloud VPS** and automatically deployed through **GitHub Actions**.

<div align="center">

```text
Local Development
       │
       ▼
     GitHub
       │
       ▼
 GitHub Actions
       │
       ▼
  Oracle Cloud
       │
       ▼
  Project Archive
```

</div>

Every update pushed to `main` is automatically deployed to the live website.
